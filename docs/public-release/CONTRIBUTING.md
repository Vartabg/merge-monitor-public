# Contributing

Start with a reproducible problem or a specific improvement. Include expected and actual behavior, the affected revision, and a small test case. Keep personal project paths, transcripts, credentials and board state out of submissions.

Work in an isolated branch or worktree. Run `npm ci`, `npm run verify`, and `node scripts/demo-handoff.mjs` locally. UI changes should also be checked in a browser with keyboard navigation and a narrow viewport. Do not add hosted GitHub Actions; this project uses local checks.

Pull requests should describe what changed, why, how it was checked, and what remains uncertain. A passing merge preview does not establish functional correctness. The owner reviews and merges contributions.

For security issues, use the private reporting contact in SECURITY.md rather than a public reproduction containing sensitive data.
